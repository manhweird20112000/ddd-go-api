# ADR 0005: Ed25519 access tokens and rotating refresh sessions

Status: accepted, 2026-10-19.

Identity signs 15-minute access JWTs with Ed25519 and checks issuer, audience, issued-at time, expiry, and algorithm. The 64-byte private key comes from a Base64 environment secret. The public key verifies tokens without sharing signing authority. Passwords use Argon2id.

Refresh tokens are random values returned once to the client; PostgreSQL stores only SHA-256 hashes. Rotation creates a new token in the same family and marks the old one used. Reuse revokes the family. API idempotency responses are encrypted at rest because login and refresh responses contain raw refresh tokens. Signing-key and idempotency-key rotation need a coordinated operational procedure before use in production.
